# Module 4 — Créer des visuels et des formats courts (8 minutes)

## Contexte visuel
Screencast de Canva ou Gamma avec création de carrousel.

## Script

Le texte, c'est bien. Mais sur LinkedIn et Instagram, les visuels captent l'attention.

Pas besoin d'être designer. L'IA peut t'aider à concevoir des visuels simples et efficaces.

### Carrousel LinkedIn 5 slides

Template de script à donner à l'IA :

```
Tu es un créateur de carrousels LinkedIn.
Thème : [sujet].
Public : [profil].
Crée un carrousel de 5 slides.
Pour chaque slide, donne :
- le titre (5 mots maximum)
- le contenu (1 à 2 phrases)
- la recommandation visuelle (icône, couleur, image)
Le ton doit être [ton].
```

Tu peux ensuite reproduire ces slides dans Canva en 10 minutes.

### Prompts pour descriptions d'images

Si tu utilises un générateur d'images comme Midjourney ou DALL-E :

```
Crée une image minimaliste pour un post LinkedIn sur [sujet].
Style : professionnel, épuré, couleurs [violet et cyan].
Pas de texte dans l'image.
Format : carré 1080x1080.
```

### Formats courts : Reels / Shorts

Pour une vidéo courte, demande à l'IA :

```
Rédige un script de 60 secondes sur [sujet].
Public : [profil].
Ton : [ton].
Structure : accroche en 3 secondes, 3 points clés, appel à l'action.
Indique les éléments visuels suggérés.
```

### Outils recommandés

- **Canva** : carrousels, posts, visuels simples
- **Gamma** : présentations stylées
- **CapCut** : montage vidéo rapide
- **Midjourney / DALL-E** : images générées par IA

Dans le prochain module, on organise tout ça dans une routine hebdomadaire.
