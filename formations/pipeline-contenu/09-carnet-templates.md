# Carnet de templates — Pipeline de contenu IA

## Comment utiliser ce carnet

Ce carnet contient tous les prompts et templates utilisés dans la formation "Pipeline de contenu IA".

Copie-colle les prompts dans ChatGPT, Claude ou Gemini. Remplace les éléments entre crochets par tes informations.

---

## Template 1 — Générer 30 idées de contenu

```
Tu es un rédacteur marketing spécialisé dans [ton secteur].
Mon audience est [profil].
Mon objectif de contenu est [générer des leads / éduquer / vendre un service].
Mes 3 thématiques principales sont : [thème 1], [thème 2], [thème 3].
Génère 30 idées de contenu pour [LinkedIn / blog / newsletter].
Pour chaque idée, donne :
- un titre accrocheur
- le format (post texte, carrousel, vidéo courte, article)
- une accroche en 1 phrase
- l'appel à l'action suggéré
Classer les idées par semaine.
```

## Template 3 — Prompt de rédaction LinkedIn

```
Tu es un rédacteur LinkedIn expert pour [ton secteur].
Mon audience est [profil cible].
Mon ton est [pédagogique / direct / inspirant / technique].
Voici l'idée de post : [titre + angle].
Rédige un post LinkedIn de 150 mots maximum avec :
- Une accroche qui stoppe le scroll
- 3 à 5 lignes courtes au milieu
- Un point de vue ou une expérience personnelle
- Un appel à l'action à la fin
- 3 hashtags pertinents
```

## Template 4 — Prompt pour carrousel LinkedIn

```
Transforme ce post LinkedIn en un carrousel de 5 slides maximum :

[Colle ici ton post]

Pour chaque slide, donne :
- Le titre de la slide (3 mots maximum)
- La phrase principale (10 mots maximum)
- L'idée visuelle suggérée

Le premier slide doit être une accroche forte.
Le dernier slide doit contenir un appel à l'action.
```

## Template 5 — Les 5 formats de posts

### 1. Post apprentissage
```
Voici 3 choses que j'ai apprises cette semaine sur [sujet] :

1. [Apprentissage 1]
2. [Apprentissage 2]
3. [Apprentissage 3]

Laquelle tu appliques dès demain ?
```

### 2. Post erreur
```
J'ai perdu [X heures / X euros] hier à cause de cette erreur.

[Description courte]

Voici comment l'éviter :
[Solution en 3 points]

Ne fais pas comme moi.
```

### 3. Post framework
```
Ma méthode [nom] en [X] étapes :

1. [Étape 1]
2. [Étape 2]
3. [Étape 3]
4. [Étape 4]
5. [Étape 5]

Enregistre ce post. Tu en auras besoin.
```

### 4. Post résultat
```
Comment j'ai [obtenu un résultat] avec [méthode/outil].

[Contexte]

Le déclencheur : [étape clé]
Le résultat : [chiffre ou impact]

Tu veux le même résultat ? [CTA]
```

### 5. Post opinion
```
Tout le monde dit [opinion commune].

Voici pourquoi je ne suis pas d'accord.

[Argument 1]
[Argument 2]
[Argument 3]

Et toi, qu'est-ce que tu en penses ?
```

## Template 10 — Routine mensuelle de 2h

**Minute 0-20 : Générer les idées**
- Lance le prompt de 30 idées
- Sélectionne les 12 meilleures

**Minute 20-35 : Planifier**
- Répartis les 12 idées sur 4 semaines
- Choisis les formats

**Minute 35-80 : Rédiger**
- Génère les 12 posts
- Passe en revue et ajuste le ton

**Minute 80-95 : Visuels**
- Crée 4 visuels pour les carrousels

**Minute 95-120 : Programmer**
- Planifie dans Buffer / Metricool / Notion
- Vérifie les dates
