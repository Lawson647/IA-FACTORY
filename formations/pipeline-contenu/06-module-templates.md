# Module 6 — Templates prêts à l'emploi (7 minutes)

## Contexte visuel
Face caméra avec partage d'écran montrant les templates.

## Script

Dans ce dernier module, je te donne 4 templates prêts à l'emploi que tu peux copier-coller dans l'IA.

### Template 1 — Post LinkedIn

```
Rédige un post LinkedIn de 200 mots sur [sujet].
Audience : [profil].
Objectif : [générer des leads / éduquer].
Structure : accroche en question, problème, solution, témoignage ou exemple, appel à l'action.
Ton : professionnel mais accessible.
3 hashtags pertinents.
```

### Template 2 — Newsletter

```
Rédige une newsletter sur [sujet].
Audience : [profil].
Objectif : [fidéliser / vendre].
Structure : objet accrocheur, intro de 50 mots, 3 sections avec sous-titres, conclusion avec CTA.
Ton : pédagogique et chaleureux.
```

### Template 3 — Article de blog

```
Rédige un article SEO de 800 mots sur [sujet].
Public : [profil].
Structure : intro, 4 parties avec H2, conclusion avec CTA.
Langage simple, phrases courtes.
Ajoute une méta-description de 160 caractères.
```

### Template 4 — Carrousel 5 slides

```
Crée un carrousel LinkedIn de 5 slides sur [sujet].
Public : [profil].
Pour chaque slide : titre de 5 mots max, contenu de 1 à 2 phrases, suggestion visuelle.
Ton : inspirant et actionnable.
```

### Ton devoir

Prends un de ces templates. Choisis un sujet qui te tient à cœur. Génère ton premier contenu aujourd'hui.

Puis programme-le pour demain.

Et recommence la semaine prochaine.
