# Module 5 — Déploiement et prochaines étapes (7 minutes)

## Contexte visuel
Face caméra, ton encourageant. Appel à l'action vers la communauté Skool et le Pack IA Factory.

## Script

Félicitations. Tu as maintenant un agent IA opérationnel.

Dans cette formation, on a vu :
- Ce qu'est un agent IA
- Comment choisir la bonne tâche à automatiser
- Comment construire un agent pas à pas avec n8n ou Make
- Comment le sécuriser et le fiabiliser

Maintenant, il est temps de le mettre en production.

### Étape 1 : activer l'agent

Dans n8n ou Make, passe ton workflow en mode "Actif" ou "On". Vérifie que le webhook est bien connecté à ton formulaire.

### Étape 2 : documenter rapidement

Crée un petit document avec :
- Le nom de l'agent
- Sa fonction
- Le déclencheur
- Les outils connectés
- Les limites

Ça te servira dans 3 mois quand tu auras oublié les détails.

### Étape 3 : mesurer le temps gagné

Note pendant 2 semaines :
- Combien de fois l'agent a fonctionné
- Combien de temps tu aurais passé à faire ces tâches toi-même

Tu seras souvent surpris du résultat.

### Prochaines étapes

Si tu veux aller plus loin, je te propose deux choses :

1. Rejoins la communauté Les Ateliers IA sur Skool. On partage des workflows, des prompts agents, et on s'entraide quand un agent ne fonctionne pas.

2. Découvre le Pack IA Factory. Pour 149 euros, tu accèdes à vie à 3 formations : "10 prompts pour gagner 2h par jour", "Créer ton premier agent IA" et "Pipeline de contenu IA". Plus les 50 prompts et le plan d'action 30 jours.

Merci d'avoir suivi cette formation. Maintenant, crée ton deuxième agent.

À très vite.
