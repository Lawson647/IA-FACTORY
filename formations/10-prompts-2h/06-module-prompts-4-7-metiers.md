# Module 6 — Prompts 4 à 7 : Les prompts métier par profil (12 minutes)

## Contexte visuel
Screencast rapide avec plusieurs exemples de prompts par profil.

## Script

Dans ce module, on passe aux prompts adaptés à des métiers concrets. Même si tu n'exerces pas ces métiers, inspire-toi de la structure : tu pourras facilement adapter à ton activité.

### Prompt 4 — Assistant administratif

"Tu es un assistant administratif efficace.
Voici une liste de tâches à traiter : [liste].
Rédige pour chaque tâche le message ou le document nécessaire.
Format : tableau avec tâche, message/document, destinataire."

Exemple d'utilisation : relances clients, demandes de documents, confirmations de rendez-vous.

### Prompt 5 — Commercial

"Tu es un commercial B2B dans le secteur [secteur].
J'ai un prospect [profil].
Rédige une séquence de 3 emails de prospection espacés de 3 jours.
Ton : professionnel mais humain.
Objectif : obtenir un appel de 15 minutes.
À la fin, donne-moi une phrase de suivi téléphonique."

### Prompt 6 — Formateur / Coach

"Tu es un formateur pédagogue dans le domaine [domaine].
Je veux créer une formation de [durée] sur [sujet].
Public cible : [profil].
Donne-moi :
- un plan détaillé en 5 modules
- 3 objectifs pédagogiques
- 2 exercices pratiques
- un QCM de 5 questions avec corrigé"

### Prompt 7 — Consultant / Freelance

"Tu es un consultant expérimenté.
Mon client [profil] me demande [besoin].
Rédige une proposition commerciale de [durée] structurée en :
1. Compréhension du besoin
2. Méthodologie
3. Livrables
4. Investissement
5. Prochaines étapes
Ton : professionnel, valorisant, pas trop formel."

### Astuce transversale

Ces 4 prompts ont la même structure : rôle + contexte + format de sortie. C'est la base de tout bon prompt. Une fois que tu as compris ce pattern, tu peux le répéter pour n'importe quel métier.

Exercice : choisis le prompt qui ressemble le plus à ton activité et teste-le aujourd'hui avec un cas réel.
