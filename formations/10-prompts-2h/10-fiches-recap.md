# Fiches récap — 10 prompts pour gagner 2h par jour

## IA Factory — Formation pratique

---

## ✅ Les 3 règles d'un bon prompt

1. **Donner un rôle** à l'IA  
   Ex : "Tu es un commercial B2B expérimenté..."

2. **Décrire le contexte et le résultat attendu**  
   Ex : "Mon client n'a pas répondu au devis depuis 10 jours. Rédige un email de relance chaleureux."

3. **Demander un format de sortie structuré**  
   Ex : "Propose-moi 2 variantes" / "Résume en 5 points clés" / "Format tableau"

---

## 📧 Prompt 1 — Email professionnel

```
Tu es un [rôle].
Rédige un email [type] à destination de [destinataire].
Contexte : [contexte].
Ton : [ton].
Longueur : [longueur].
Objectif : [objectif].
Propose-moi 2 variantes.
```

**Astuce :** ajoute "Ajoute 3 suggestions d'objet d'email."

---

## 📄 Prompt 2 — Résumer un document

```
Résume le texte ci-dessous pour un [profil].
Format souhaité : [5 points clés / 3 paragraphes].
Niveau de détail : [synthétique / moyen / détaillé].
À la fin, indique les 3 actions ou décisions à retenir.

[coller le texte]
```

**Astuce :** pour un email long : "Résume en 3 phrases. Quelle est l'action attendue ?"

---

## 📱 Prompt 3 — Plan de contenu

```
Tu es un rédacteur marketing spécialisé dans [secteur].
Mon audience est [profil].
Je veux un plan de contenu pour [LinkedIn / blog / newsletter] sur [durée].
Thématiques : [liste].
Objectif : [objectif].
Ton : [ton].
Format : tableau avec date, type, titre, accroche, appel à l'action.
```

---

## 💼 Prompts 4 à 7 — Par métier

### 4. Assistant administratif
```
Tu es un assistant administratif efficace.
Voici des tâches à traiter : [liste].
Rédige pour chaque tâche le message ou document nécessaire.
Format : tableau.
```

### 5. Commercial
```
Tu es un commercial B2B dans [secteur].
Prospect : [profil].
Rédige une séquence de 3 emails de prospection espacés de 3 jours.
Objectif : obtenir un appel de 15 minutes.
```

### 6. Formateur / Coach
```
Tu es un formateur pédagogue dans [domaine].
Formation de [durée] sur [sujet].
Public : [profil].
Donne un plan en 5 modules, 3 objectifs, 2 exercices, un QCM de 5 questions.
```

### 7. Consultant / Freelance
```
Tu es un consultant expérimenté.
Client : [profil]. Besoin : [besoin].
Rédige une proposition structurée : besoin, méthodologie, livrables, investissement, prochaines étapes.
```

---

## 🚀 Prompts 8 à 10 — Avancés

### 8. Reformuler un texte compliqué
```
Tu es un rédacteur pédagogue.
Reformule ce texte pour le rendre [clair / accessible] pour [public].
Règles : phrases courtes, vocabulaire simple, pas de jargon.

[coller le texte]
```

### 9. Résoudre un problème bloquant
```
Tu es un consultant stratégique.
Problème : [décrire].
Objectif : [objectif].
Contraintes : [liste].
Propose 5 idées d'action, du plus simple au plus ambitieux.
Pour chaque : avantages, inconvénients, délai.
```

### 10. Créer un agent simple
```
Tu es un [rôle]. Ta mission est de [tâche].
Quand je te donne [input], tu dois [output].
Ton : [ton].
Tu ne dois jamais [règle].
Si une information manque, demande-la-moi.
```

## 🎯 Routine matinale de 10 minutes

1. **Quelle tâche répétitive puis-je confier à l'IA aujourd'hui ?**
2. Choisir le prompt adapté dans ma bibliothèque.
3. Copier-coller et remplacer les éléments entre crochets.
4. Valider le résultat en 1 minute.
5. Passer à la tâche suivante.

---

## 📚 Comment créer ma bibliothèque personnelle

1. Ouvrir un document (Notion, Word, Google Docs).
2. Copier les templates des prompts utilisés.
3. Ajouter 1 exemple concret par prompt.
4. Mettre à jour chaque semaine.
5. Partager les meilleurs dans la communauté Skool.
