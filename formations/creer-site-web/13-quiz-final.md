# Quiz final — Créer son site web avec l'IA

## Question 1
Quel est le premier élément à définir avant de créer un site ?

A. Le nom de domaine  
B. L'objectif principal du site  
C. La couleur du logo  
D. Le nombre d'images

**Réponse : B**

## Question 2
Quel outil est recommandé pour débuter sans coder ?

A. Visual Studio Code  
B. Lovable  
C. Photoshop  
D. Excel

**Réponse : B**

## Question 3
Quelle page est indispensable pour un site vitrine ?

A. Page d'accueil  
B. Page admin  
C. Page API  
D. Page de paiement

**Réponse : A**

## Question 4
Qu'est-ce qu'un wireframe ?

A. Un outil de développement  
B. Un schéma de la structure de la page  
C. Un type de serveur  
D. Un langage de programmation

**Réponse : B**

## Question 5
Pourquoi faut-il relire le contenu généré par l'IA ?

A. Pour corriger les erreurs et ajouter sa voix  
B. Parce que l'IA est toujours fausse  
C. Pour augmenter la taille du texte  
D. Ce n'est pas nécessaire

**Réponse : A**

## Question 6
Quel est le rôle d'un CTA ?

A. Décorer la page  
B. Guider l'utilisateur vers une action  
C. Ralentir le visiteur  
D. Ajouter du texte

**Réponse : B**

## Question 7
Qu'est-ce que le HTTPS ?

A. Un type de design  
B. Un protocole sécurisé pour les sites web  
C. Un outil de newsletter  
D. Un framework

**Réponse : B**

## Question 8
Pourquoi soumettre un sitemap ?

A. Pour rendre le site plus beau  
B. Pour aider Google à indexer les pages  
C. Pour recevoir des emails  
D. Pour créer des images

**Réponse : B**

## Question 9
Quel est l'intérêt d'une meta description ?

A. Améliorer le référencement et inciter au clic  
B. Changer les couleurs du site  
C. Augmenter la vitesse du site  
D. Remplacer le titre

**Réponse : A**

## Question 10
Quelle est la dernière étape après la mise en ligne ?

A. Supprimer le site  
B. Promouvoir le site et créer du contenu  
C. Changer de nom de domaine  
D. Refaire tout le design

**Réponse : B**
