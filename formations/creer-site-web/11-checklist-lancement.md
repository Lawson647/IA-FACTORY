# Checklist de lancement — Créer son site web

## Avant la mise en ligne
- [ ] Le brief est clair
- [ ] Les pages sont définies
- [ ] Le contenu est rédigé et relu
- [ ] Le design est validé
- [ ] Le site est responsive
- [ ] Les liens fonctionnent
- [ ] Le formulaire de contact fonctionne
- [ ] Les images sont optimisées

## SEO
- [ ] Titre unique sur chaque page
- [ ] Meta description rédigée
- [ ] H1 présent sur chaque page
- [ ] Sitemap.xml créé
- [ ] Robots.txt créé
- [ ] Google Search Console configuré

## Mise en ligne
- [ ] Nom de domaine acheté
- [ ] Hébergement configuré
- [ ] Site déployé
- [ ] HTTPS activé
- [ ] Emails professionnels créés

## Après le lancement
- [ ] Analytics installé
- [ ] Réseaux sociaux liés
- [ ] Premier post LinkedIn
- [ ] Newsletter branchée
- [ ] Plan de contenu sur 30 jours
