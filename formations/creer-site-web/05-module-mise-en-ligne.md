# Module 5 — Mettre le site en ligne (10 minutes)

## Contexte visuel
Screencast Lovable + Vercel + OVH. Avatar en bas à droite.

## Script

Ton site est prêt. Il est temps de le rendre accessible au public.

### Étape 1 : déployer avec Lovable

Dans Lovable, clique sur "Deploy". Tu obtiens un lien public.

C'est déjà fonctionnel. Mais pour une URL pro, il faut aller plus loin.

### Étape 2 : connecter un nom de domaine

Achete un nom de domaine chez OVH, Namecheap ou GoDaddy.

Exemples d'URL professionnelles :
- tonprenom-ia.fr
- tonactivite-ia.com
- tonentreprise.fr

Ensuite, connecte-le à Vercel ou Netlify en modifiant les DNS.

### Étape 3 : configurer les emails professionnels

Avec ton nom de domaine, crée une adresse email pro comme contact@tonactivite.fr.

### Étape 4 : tester sur tous les appareils

Ouvre ton site sur :
- ton téléphone
- une tablette
- un ordinateur

Vérifie :
- la vitesse de chargement
- la lisibilité
- les liens
- le formulaire

### Étape 5 : activer le HTTPS

Avec Vercel ou Netlify, le HTTPS est automatique. C'est indispensable pour la confiance et le SEO.

Félicitations, ton site est en ligne. Maintenant, il faut le faire connaître.
