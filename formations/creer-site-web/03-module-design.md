# Module 3 — Créer le design avec l'IA (12 minutes)

## Contexte visuel
Screencast Lovable. Avatar en bas à droite.

## Script

On arrive dans Lovable. Si tu n'as pas encore de compte, crée-en un gratuitement sur lovable.dev.

### Étape 1 : créer un nouveau projet

Clique sur "New Project" et choisis de partir de zéro.

### Étape 2 : coller le brief

Reprends le brief que tu as préparé dans le module 2 : objectif du site, public cible, pages nécessaires, ton et couleurs.

Exemple de prompt :

```
Crée un site vitrine pour un formateur IA indépendant.
Public : indépendants et TPE en France.
Pages : accueil, formations, à propos, contact.
Design : moderne, sombre, accents cyan et violet.
Style : tech, professionnel, accessible.
Langue : français.
```

### Étape 3 : itérer sur le design

Lovable va générer une première version. Ensuite, tu peux demander des modifications dans le chat.

Exemples de prompts :
- "Change le titre pour qu'il soit plus accrocheur"
- "Ajoute une section avec 3 cartes d'avantages"
- "Remplace cette image par un visuel plus tech"
- "Agrandis le bouton d'appel à l'action"
- "Ajoute un footer avec les réseaux sociaux"

### Étape 4 : vérifier le responsive

Lovable génère des sites responsive par défaut. Passe en mode mobile pour vérifier que tout est lisible.

### Étape 5 : ajouter les pages manquantes

Demande à Lovable de créer les pages supplémentaires :
- "Crée une page À propos avec une photo, une bio et un CTA"
- "Crée une page Formations avec 3 cartes de formations"
- "Crée une page Contact avec un formulaire"

Dans le prochain module, on remplit ces pages avec du contenu.
