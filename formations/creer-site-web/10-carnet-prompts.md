# Carnet de prompts — Créer son site web avec l'IA

## Prompt 1 : Générer la structure d'une page
```
Je crée un site pour [activité].
Public cible : [profil].
Objectif de la page : [objectif].
Génère une structure complète avec : un titre H1, 3 à 5 sections, des sous-titres, et un appel à l'action.
```

## Prompt 2 : Rédiger un hero accrocheur
```
Rédige un titre et un sous-titre pour la page d'accueil de [activité].
Promesse : [promesse].
Public : [profil].
Ton : [ton].
Titre : 8 mots maximum. Sous-titre : 20 mots maximum.
```

## Prompt 3 : Générer une page À propos
```
Rédige une page "À propos" pour [activité].
Nom : [ton nom].
Parcours : [3 lignes].
Pourquoi cette activité : [raison].
CTA : [action souhaitée].
Longueur : 250 mots.
```

## Prompt 4 : Créer une section avantages
```
Génère 3 cartes d'avantages pour [offre].
Pour chaque carte : un titre de 3 mots, une description de 20 mots, une icône suggérée.
```

## Prompt 5 : Rédiger une meta description
```
Rédige une meta description de 150 caractères maximum pour [page].
Objectif : [SEO / clic].
Mots-clés : [mots-clés].
```

## Prompt 6 : Générer un formulaire de contact
```
Crée les champs d'un formulaire de contact pour [site].
Pour chaque champ : nom, type, obligatoire ou non, message d'erreur.
```

## Prompt 7 : Optimiser un texte pour le web
```
Rends ce texte plus lisible et persuasif pour une page web :
[coller le texte]
```

## Prompt 8 : Créer un CTA
```
Propose 5 formulations de bouton d'appel à l'action pour [objectif].
Exemple : obtenir un devis, télécharger le guide, s'inscrire.
```

## Prompt 9 : Générer des idées de blog
```
Génère 10 idées d'articles de blog pour [site].
Public : [profil].
Pour chaque idée : titre accrocheur et angle original.
```

## Prompt 10 : Créer un brief Lovable
```
Crée un site web pour [activité].
Public : [profil].
Objectif : [objectif].
Pages : [pages].
Design : [style], couleurs [couleurs].
Langue : français.
```
