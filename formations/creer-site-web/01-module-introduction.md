# Module 1 — Introduction : pourquoi créer son site web avec l'IA (8 minutes)

## Contexte visuel
Face caméra + avatar. Fond dégradé sombre IA Factory.

## Script

En 2025, avoir un site web n'est plus un luxe. C'est une nécessité.

Que tu sois indépendant, freelance, formateur ou dirigeant de TPE, ton site web est :
- ta vitrine professionnelle
- ton outil de capture de leads
- ton vendeur qui travaille 24h/24
- ton support de crédibilité

Le problème, c'est qu'avant, créer un site web coûtait cher, prenait du temps et demandait des compétences techniques.

Aujourd'hui, avec l'IA, ça a complètement changé.

Des outils comme Lovable, v0 de Vercel, ou même WordPress avec des plugins IA, te permettent de créer un site web professionnel en quelques heures, sans écrire une ligne de code.

Dans cette formation, on va créer ensemble un site web complet. Pas une maquette. Un vrai site, en ligne, avec plusieurs pages, un formulaire de contact et un design moderne.

À la fin, tu auras un site prêt à recevoir tes premiers visiteurs.
