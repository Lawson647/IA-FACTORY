# Module 2 — Structurer son site web (10 minutes)

## Contexte visuel
Screencast Notion ou document texte + avatar.

## Script

Avant de créer le design, il faut structurer le site.

### Étape 1 : définir l'objectif principal

Ton site ne peut pas tout faire. Il doit avoir un objectif clair.

Exemples :
- Capturer des emails pour ta newsletter
- Vendre une formation
- Obtenir des demandes de devis
- Présenter ton activité et ton portfolio

### Étape 2 : choisir les pages

Pour un site vitrine classique, on recommande :
- **Accueil** : accroche, promesse, CTA
- **Offre / Services** : ce que tu proposes et à quel prix
- **À propos** : qui tu es, pourquoi toi
- **Contact** : formulaire ou email
- **Blog** (optionnel) : pour le SEO

### Étape 3 : rédiger le contenu avec l'IA

Utilise ce prompt pour générer la structure d'une page :

```
Je crée un site web pour [mon activité].
Public cible : [profil].
Objectif de la page : [objectif].
Génère une structure de page avec : un titre accrocheur, 3 à 5 sections, un appel à l'action, et les textes pour chaque section.
```

### Étape 4 : créer un wireframe simple

Un wireframe, c'est un schéma de la page. Tu peux le faire sur papier, dans Notion, ou avec un prompt IA.

Exemple de prompt pour un wireframe :

```
Décris un wireframe pour une landing page avec :
1. Un hero avec titre, sous-titre et bouton
2. Une section avantages avec 3 cartes
3. Une section témoignages
4. Une section tarifs
5. Un formulaire de contact
```

### Exercice

Pour ton site, rédige :
- La promesse principale
- Les 3 pages essentielles
- Le CTA principal

Dans le prochain module, on ouvre Lovable et on génère le design.
