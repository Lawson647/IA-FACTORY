# Fiches récap — Créer son site web avec l'IA

## Fiche 1 — Les 5 pages essentielles

| Page | Objectif | Contenu clé |
|------|----------|-------------|
| Accueil | Accrocher et convertir | Hero, promesse, CTA |
| Offre | Présenter les services | Prix, bénéfices, garantie |
| À propos | Créer la confiance | Bio, parcours, photo |
| Contact | Faciliter la prise de contact | Formulaire, email, téléphone |
| Blog | Attirer du trafic SEO | Articles réguliers |

## Fiche 2 — Les 3 critères d'un bon site

1. **Clair** : en 5 secondes, on comprend ce que tu fais.
2. **Rapide** : le site se charge en moins de 3 secondes.
3. **Action** : il y a un CTA visible sur chaque page.

## Fiche 3 — Outils par niveau

| Niveau | Outil recommandé |
|--------|------------------|
| Débutant | Lovable ou v0 |
| Intermédiaire | Webflow |
| Avancé | Next.js + Vercel |

## Fiche 4 — Prompt essentiel Lovable

```
Crée un site [type] pour [activité].
Public : [profil].
Objectif : [objectif].
Pages : [liste].
Style : [moderne / minimaliste / tech].
Couleurs : [couleurs].
Langue : français.
```

## Fiche 5 — SEO rapide

1. Un H1 par page
2. Title unique (< 60 caractères)
3. Meta description (< 160 caractères)
4. Sitemap soumis
5. Images avec alt text
