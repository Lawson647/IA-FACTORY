# Carnet de prompts — Vibe Coding

## Prompt 1 : Générer un brief complet
```
Je veux créer une application web appelée [nom].
Public cible : [profil].
Problème résolu : [problème].
Fonctionnalités MVP :
1. [Fonctionnalité 1]
2. [Fonctionnalité 2]
3. [Fonctionnalité 3]
Design : moderne, professionnel, couleurs [couleurs].
Langue : français.

Génère un brief complet avec : description, pages nécessaires, fonctionnalités détaillées, suggestions de design.
```

## Prompt 2 : Créer une page dans Lovable
```
Crée une page [nom de la page] avec :
- Un titre [titre]
- Un sous-titre [sous-titre]
- Un bouton d'action principal [CTA]
- [Autres éléments]
```

## Prompt 3 : Modifier le design
```
Modifie le design de l'application avec :
- Fond sombre #05050f
- Accents cyan #22d3ee et violet #a78bfa
- Police moderne et lisible
- Boutons arrondis
```

## Prompt 4 : Ajouter une fonctionnalité
```
Ajoute une fonctionnalité qui permet à l'utilisateur de [action].
Inclure : le formulaire, la validation, le message de confirmation.
```

## Prompt 5 : Corriger un bug
```
L'application affiche cette erreur : [message d'erreur].
Corrige le problème et explique brièvement ce qui était cassé.
```

## Prompt 6 : Générer du contenu
```
Rédige le contenu des pages suivantes pour l'application [nom] :
- Page d'accueil
- Page à propos
- Page fonctionnalités
Ton : professionnel et accessible.
```

## Prompt 7 : Créer un tableau de bord
```
Crée un dashboard avec :
- Un tableau listant les [éléments]
- Des statistiques clés en haut de page
- Un bouton pour ajouter un nouvel élément
```

## Prompt 8 : Ajouter l'authentification
```
Ajoute une authentification utilisateur avec :
- Page de connexion
- Page d'inscription
- Déconnexion
- Protection des pages privées
```

## Prompt 9 : Créer un formulaire avancé
```
Crée un formulaire avec les champs suivants :
[Nom, Email, Téléphone, Message]
Ajoute la validation des champs et un message de confirmation.
```

## Prompt 10 : Préparer le déploiement
```
Prépare l'application pour le déploiement sur Vercel.
Vérifie qu'il n'y a pas d'erreurs et donne-moi les étapes à suivre.
```
