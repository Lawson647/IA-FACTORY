# Formation : Vibe Coding — Créer ton premier SaaS/app avec l'IA

## Objectif pédagogique
À l'issue de cette formation, l'apprenant sera capable de créer une application web fonctionnelle (SaaS, outil interne, landing page avancée) avec l'aide de l'IA, sans écrire de code manuellement, en utilisant les outils de Vibe Coding (Lovable, v0, Bolt, Cursor).

## Public cible
- Indépendants et freelances qui veulent créer un outil pour leurs clients
- Dirigeants de TPE/PME qui veulent prototyper une application
- Formateurs et coaches qui veulent lancer une app ou un micro-SaaS
- Aucune compétence en code requise

## Prérequis
- Avoir suivi "10 prompts pour gagner 2h par jour" ou maîtriser les bases des prompts
- Disposer d'un compte ChatGPT, Claude ou Gemini
- Avoir un compte gratuit sur Lovable, v0 ou Bolt
- Une idée d'application ou de problème à résoudre

## Durée totale
- 6 modules × 8 à 12 minutes = environ 55 minutes de vidéo
- Exercices pratiques : 2h
- Total : environ 3h

## Structure des modules

### Module 1 — Introduction au Vibe Coding (8 min)
- Qu'est-ce que le Vibe Coding
- Différences avec le développement traditionnel
- Les outils disponibles : Lovable, v0, Bolt, Cursor
- Exemples d'applications créées en Vibe Coding

### Module 2 — Définir son application (10 min)
- Identifier un problème à résoudre
- Rédiger un brief IA efficace
- Définir les fonctionnalités MVP
- Créer le wireframe avec un prompt

### Module 3 — Construire l'interface avec Lovable (12 min)
- Présentation de Lovable
- Créer un projet et choisir un template
- Générer les premières pages avec des prompts
- Modifier le design, les couleurs, le texte
- Prévisualiser et itérer

### Module 4 — Ajouter la logique et les données (12 min)
- Connecter une base de données simple (Supabase ou Airtable)
- Gérer l'authentification utilisateur
- Créer des formulaires et des actions
- Tester les parcours utilisateurs

### Module 5 — Publier et partager son application (8 min)
- Déployer sur Vercel ou Netlify
- Obtenir un lien public
- Connecter un nom de domaine
- Partager l'application aux premiers utilisateurs

### Module 6 — Améliorer et itérer (5 min)
- Collecter les retours utilisateurs
- Ajouter des fonctionnalités avec des prompts
- Corriger les bugs sans coder
- Prochaines étapes : monétiser, scaler, rejoindre Skool

## Modalités pédagogiques
- Vidéos courtes avec screencasts
- Exercices pratiques entre chaque module
- Fichiers téléchargeables : brief type, prompts, checklist
- Quiz final de 10 questions
- Certificat de participation (si Qualiopi / portage en place)

## Indicateurs d'évaluation
- Quiz : 7/10 minimum
- Exercice final : livrer une application fonctionnelle avec au moins 2 pages et 1 action

## Livrables de production
- 6 scripts de vidéo
- Template de brief IA
- Carnet de prompts Vibe Coding
- Fiches récap
