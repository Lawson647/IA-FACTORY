# Module 3 — Construire l'interface avec Lovable (12 minutes)

## Contexte visuel
Screencast Lovable. Avatar en bas à droite.

## Script

On arrive dans Lovable.

Si tu n'as pas encore de compte, crée-en un gratuitement sur lovable.dev.

### Étape 1 : créer un nouveau projet

Clique sur "New Project". Tu peux partir d'un template vide ou choisir un template existant.

Pour cette formation, on part de zéro.

### Étape 2 : décrire ton application

Copie-colle le brief que tu as préparé dans le module 2.

Lovable va générer une première version de ton application : structure, pages, textes, couleurs.

### Étape 3 : itérer avec des prompts

Maintenant, tu peux demander des modifications directement dans le chat.

Exemples de prompts :
- "Ajoute une page Dashboard avec un tableau des prospects"
- "Change les couleurs pour du bleu nuit et du cyan"
- "Rends le bouton principal plus visible"
- "Ajoute un formulaire d'inscription avec email et mot de passe"

Chaque prompt génère une nouvelle version. Tu peux revenir en arrière si nécessaire.

### Étape 4 : vérifier le résultat

Prends le temps de cliquer sur tous les boutons, remplir les formulaires, naviguer entre les pages.

Note ce qui fonctionne et ce qu'il faut corriger.

Dans le prochain module, on ajoute la logique et les données.
