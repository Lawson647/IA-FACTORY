# Module 5 — Publier et partager son application (8 minutes)

## Contexte visuel
Screencast Lovable + Vercel/Netlify. Avatar en bas à droite.

## Script

Ton application est prête. Il est temps de la mettre en ligne.

### Déployer avec Lovable

Lovable propose un déploiement en un clic. Clique sur "Deploy" ou "Publish".

Tu obtiens un lien public du type : `https://mon-app.lovable.app`

### Utiliser Vercel ou Netlify

Pour un nom de domaine personnalisé ou plus de contrôle, tu peux exporter le projet vers Vercel ou Netlify.

1. Connecte ton compte GitHub
2. Pousse le projet sur GitHub
3. Importe-le dans Vercel ou Netlify
4. Déploie

### Obtenir un nom de domaine

Si tu veux une URL pro comme `monapp.com`, tu peux acheter un nom de domaine chez OVH, Namecheap ou GoDaddy, puis le connecter à Vercel.

### Partager l'application

Maintenant que ton app est en ligne, partage le lien à :
- 3 collègues ou amis pour avoir des retours
- Ta communauté Skool
- LinkedIn si tu cherches des premiers utilisateurs

### Conseil

Ne cherche pas la perfection. Une application simple qui fonctionne vaut mieux qu'une application parfaite qui n'existe pas.
