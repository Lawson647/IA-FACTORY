# Fiches récap — Vibe Coding

## Fiche 1 — Le brief parfait

| Élément | À définir |
|---------|-----------|
| Nom | Court et mémorable |
| Public | Très précis |
| Problème | Concret et vécu |
| MVP | 3 fonctionnalités max |
| Design | Style + couleurs |
| Langue | Français ou anglais |

## Fiche 2 — Outils Vibe Coding

| Outil | Usage | Niveau |
|-------|-------|--------|
| Lovable | Créer des apps complètes facilement | Débutant |
| v0 (Vercel) | Générer des interfaces React | Débutant |
| Bolt (StackBlitz) | Coder en direct dans le navigateur | Intermédiaire |
| Cursor | Éditeur de code avec IA intégrée | Avancé |

## Fiche 3 — Workflow de création

```
DÉFINIR → GÉNÉRER → CONNECTER → DÉPLOYER → ITÉRER
```

1. Définir le brief
2. Générer l'interface avec Lovable
3. Connecter la base de données
4. Déployer l'application
5. Itérer avec les retours

## Fiche 4 — Checklist avant publication

- [ ] L'application s'ouvre sans erreur
- [ ] Les pages principales sont accessibles
- [ ] Les formulaires fonctionnent
- [ ] Les données s'enregistrent
- [ ] Le design est cohérent
- [ ] Le lien public est partageable

## Fiche 5 — Questions à poser aux premiers utilisateurs

1. Qu'est-ce qui est clair au premier abord ?
2. Qu'est-ce qui est confus ?
3. Quelle fonctionnalité te manque le plus ?
4. Serais-tu prêt à payer pour cette application ?
5. À qui recommanderais-tu cette app ?
