# Module 2 — Définir son application (10 minutes)

## Contexte visuel
Screencast + avatar. Document texte ou Notion.

## Script

Avant d'ouvrir Lovable, il faut savoir exactement ce qu'on veut construire.

Le Vibe Coding fonctionne mal si ton brief est flou. L'IA a besoin d'instructions claires.

### Les 3 questions fondamentales

1. **Quel problème résout ton application ?**
   Par exemple : "Aider les indépendants à suivre leurs prospects."

2. **Pour qui est-elle faite ?**
   Par exemple : "Freelances en France qui n'ont pas de CRM."

3. **Quelle est la fonctionnalité principale ?**
   Par exemple : "Ajouter un prospect, noter son statut et programmer une relance."

### Le template de brief IA

```
Je veux créer une application web appelée [nom].
Public cible : [profil].
Problème résolu : [problème].
Fonctionnalités MVP :
1. [Fonctionnalité 1]
2. [Fonctionnalité 2]
3. [Fonctionnalité 3]
Design souhaité : [moderne / minimaliste / coloré / professionnel].
Couleurs : [couleurs principales].
Langue : français.
```

### Exercice

Remplis le template avec ton propre projet. N'oublie pas : commence petit. Un MVP avec 3 fonctionnalités maximum.

Dans le prochain module, on ouvre Lovable et on génère la première version.
