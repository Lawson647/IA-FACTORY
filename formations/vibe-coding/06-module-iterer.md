# Module 6 — Améliorer et itérer (5 minutes)

## Contexte visuel
Screencast + face caméra. Récap des étapes.

## Script

Félicitations, tu as créé et déployé ta première application avec le Vibe Coding.

Maintenant, le travail continue.

### Collecter les retours

Demande à tes premiers utilisateurs :
- Ce qui est clair
- Ce qui est confus
- Ce qui manque
- Ce qu'ils aimeraient payer pour

### Itérer avec des prompts

Lovable te permet d'ajouter des fonctionnalités rapidement. Quelques exemples :
- "Ajouter une recherche dans la liste des prospects"
- "Envoyer un email de relance automatique"
- "Créer une page statistiques"
- "Ajouter un mode sombre"

### Corriger les bugs

Si quelque chose ne marche pas, copie le message d'erreur et demande à Lovable de le corriger. L'IA comprend généralement très bien les messages d'erreur.

### Prochaines étapes

- Rejoins Les Ateliers IA sur Skool pour montrer ton app
- Passe au Pack IA Factory pour maîtriser prompts, agents et contenu
- Si ton app résout un vrai problème, tu peux la monétiser

Le Vibe Coding a changé la donne. Tu n'as plus besoin d'attendre un développeur pour tester une idée.

À toi de jouer.
