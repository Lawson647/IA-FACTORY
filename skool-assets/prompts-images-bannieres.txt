# 12 Prompts pour générer les bannières Skool IA Factory

## Outils gratuits recommandés

- **Leonardo.ai** : 150 crédits/jour, excellent pour les styles artistiques
- **Bing Image Creator** : gratuit, fonctionne avec DALL-E, bon pour les illustrations
- **Ideogram.ai** : gratuit, très bon pour le texte sur les images
- **Playground AI** : version gratuite disponible

## Format conseillé

- **Ratio** : 2:1 (1200 x 600 pixels)
- **Style** : digital art, modern, premium tech, dark mode
- **Couleurs** : fond bleu nuit profond, accents violet/cyan/bleu électrique

## Conseils d'utilisation

1. **Génère 3-4 variants par prompt** et choisis la meilleure.
2. **Si le texte n'est pas lisible**, utilise Ideogram.ai qui gère mieux le texte.
3. **Télécharge en haute résolution** si l'outil propose un upscale.
4. **Recadre au format 1200 x 600** si nécessaire (Canva gratuit peut le faire).
5. **Garde une cohérence visuelle** : mêmes couleurs sombres + accents néon.

## Exemple d'image de référence IA Factory

Pour garder la cohérence avec le site, utilise ces couleurs :
- Fond : #05050f à #0a0a1f
- Violet : #a78bfa
- Bleu : #60a5fa
- Cyan : #22d3ee
- Texte : blanc
