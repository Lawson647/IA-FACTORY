# Cours Skool "Créer son site web avec l'IA"

## Informations du cours

| Champ | Valeur |
|-------|--------|
| **Titre** | Créer son site web avec l'IA |
| **Description** | Crée et mets en ligne ton propre site vitrine ou landing page en quelques heures, sans coder. 6 leçons pratiques avec Lovable, v0 et Webflow. |

## Objectif du cours

À la fin de ce cours, le membre sera capable de :
1. Définir l'objectif et la structure de son site web
2. Créer un design moderne avec Lovable ou v0
3. Rédiger le contenu des pages avec l'IA
4. Mettre son site en ligne avec un nom de domaine
5. Optimiser le SEO et les conversions

## Leçon 1 — Pourquoi créer son site web avec l'IA ?

### Durée
8 minutes

### Objectif
Comprendre l'intérêt d'avoir un site web en 2025 et découvrir les outils IA disponibles.

### Contenu
- Pourquoi un site web est indispensable aujourd'hui
- Ce que l'IA change dans la création de sites
- Les outils : Lovable, v0, Webflow, WordPress + IA, Wix + IA
- Aperçu du projet qu'on va créer ensemble

### Exercice
**Action :** Note dans un document l'objectif principal de ton futur site : vendre, capturer des emails, présenter ton activité.

### Ressources
- Vidéo 01
- Fiche "Les 5 pages essentielles"

### Script vidéo
```
En 2025, avoir un site web n'est plus un luxe. C'est une nécessité.
Que tu sois indépendant, freelance, formateur ou dirigeant de TPE, ton site web est :
- ta vitrine professionnelle
- ton outil de capture de leads
- ton vendeur qui travaille 24h/24

Avant, créer un site coûtait cher et prenait du temps.
Aujourd'hui, avec l'IA, des outils comme Lovable, v0 ou Webflow te permettent de créer un site professionnel en quelques heures.

Dans ce cours, on crée ensemble un site web complet, en ligne, avec plusieurs pages et un formulaire de contact.
```

## Leçon 2 — Structurer son site web

### Durée
10 minutes

### Objectif
Définir les pages nécessaires et préparer le contenu avant de créer le design.

### Contenu
1. Définir l'objectif principal du site
2. Choisir les pages : accueil, offre, à propos, contact, blog
3. Rédiger le contenu avec ChatGPT/Claude
4. Créer un wireframe simple

### Exercice
**Action :** Rédige dans Notion ou sur papier :
- La promesse principale de ton site
- Les 3 pages essentielles
- Le CTA principal

### Ressources
- Vidéo 02
- Template de brief site web (PDF)

### Script vidéo
```
Avant d'ouvrir Lovable, il faut savoir exactement ce qu'on veut construire.

Étape 1 : objectif principal
Ton site ne peut pas tout faire. Un seul objectif clair :
- capturer des emails
- vendre une formation
- obtenir des devis
- présenter ton activité

Étape 2 : choisir les pages
Pour un site vitrine classique :
- Accueil : accroche + promesse + CTA
- Offre/Services : ce que tu proposes et à quel prix
- À propos : qui tu es
- Contact : formulaire
- Blog (optionnel) : pour le SEO

Étape 3 : rédiger avec l'IA
Utilise ce prompt :
"Je crée un site pour [activité]. Public cible : [profil]. Objectif de la page : [objectif]. Génère une structure avec titre, 3 à 5 sections, CTA."

Étape 4 : wireframe
Un wireframe, c'est un schéma simple de la page. Tu peux le faire sur papier ou avec un prompt IA.
```

## Leçon 3 — Créer le design avec l'IA

### Durée
12 minutes

### Objectif
Générer une landing page moderne avec Lovable et itérer avec des prompts.

### Contenu
1. Créer un compte Lovable
2. Créer un projet et coller le brief
3. Itérer avec des prompts
4. Vérifier le responsive
5. Ajouter les pages manquantes

### Exercice
**Action :** Crée un projet Lovable, colle ton brief et génère ta première version du site.

### Ressources
- Vidéo 03
- Carnet de prompts site web (PDF)

### Script vidéo
```
On arrive dans Lovable. Crée un compte gratuit sur lovable.dev.

Étape 1 : new project
Choisis de partir de zéro.

Étape 2 : coller le brief
Reprends ton brief du module 2 : objectif, public, pages, ton, couleurs.

Exemple de prompt :
"Crée un site vitrine pour un formateur IA indépendant. Public : indépendants et TPE en France. Pages : accueil, formations, à propos, contact. Design : moderne, sombre, accents cyan et violet."

Étape 3 : itérer
Demande des modifications dans le chat :
- "Change le titre pour qu'il soit plus accrocheur"
- "Ajoute une section avec 3 cartes d'avantages"
- "Agrandis le bouton d'appel à l'action"

Étape 4 : responsive
Passe en mode mobile pour vérifier l'affichage.

Étape 5 : pages supplémentaires
Demande à Lovable de créer les pages manquantes.
```

## Leçon 4 — Ajouter le contenu et les pages

### Durée
10 minutes

### Objectif
Remplir le site avec des textes percutants, des images adaptées et un formulaire de contact.

### Contenu
1. Rédiger les textes avec ChatGPT/Claude
2. Relire et personnaliser
3. Choisir les images (Unsplash, Pexels, illustrations IA)
4. Créer une page offre avec prix
5. Créer un formulaire de contact

### Exercice
**Action :** Rédige les textes du hero et de la page "À propos" pour ton site. Utilise au moins un prompt IA.

### Ressources
- Vidéo 04
- Carnet de 10 prompts site web (PDF)

### Script vidéo
```
Un beau design sans bon contenu, c'est inutile.

Étape 1 : rédiger avec l'IA
Pour chaque section, demande à ChatGPT ou Claude un brouillon.
Prompt pour le hero :
"Rédige un titre et sous-titre pour la page d'accueil d'un site de formation IA. Public : indépendants et TPE en France. Promesse : apprendre l'IA pour gagner du temps."

Étape 2 : relire
Ajoute ta voix. Supprime les généralités. Mets tes vrais chiffres et exemples.

Étape 3 : images
Unsplash, Pexels pour les photos. Ideogram ou Leonardo pour les illustrations.

Étape 4 : page offre
Ta page offre doit contenir : promesse, bénéfices, prix, garantie, CTA.

Étape 5 : formulaire
Demande à Lovable : "Ajoute un formulaire de contact avec nom, email, message."
```

## Leçon 5 — Mettre le site en ligne

### Durée
10 minutes

### Objectif
Déployer le site, connecter un nom de domaine et configurer les emails professionnels.

### Contenu
1. Déployer avec Lovable
2. Connecter un nom de domaine
3. Configurer les emails pro
4. Tester sur mobile, tablette, desktop
5. Activer le HTTPS

### Exercice
**Action :** Déploie ton site avec Lovable et teste-le sur ton téléphone.

### Ressources
- Vidéo 05
- Checklist de lancement site web (PDF)

### Script vidéo
```
Ton site est prêt. Il est temps de le mettre en ligne.

Étape 1 : deploy
Dans Lovable, clique sur Deploy. Tu obtiens un lien public.

Étape 2 : nom de domaine
Achète un domaine chez OVH, Namecheap ou GoDaddy.
Exemples : tonprenom-ia.fr, tonactivite.com
Connecte-le à Vercel ou Netlify en modifiant les DNS.

Étape 3 : emails pro
Crée une adresse contact@tondomaine.fr.

Étape 4 : tests
Ouvre ton site sur téléphone, tablette et ordinateur.
Vérifie vitesse, lisibilité, liens, formulaire.

Étape 5 : HTTPS
Avec Vercel ou Netlify, le HTTPS est automatique. C'est indispensable.
```

## Leçon 6 — SEO, conversions et prochaines étapes

### Durée
5 minutes

### Objectif
Optimiser le référencement, suivre les visites et planifier le contenu futur.

### Contenu
1. Titre et meta description de chaque page
2. Sitemap.xml et robots.txt
3. Google Search Console
4. Google Analytics ou Plausible
5. Prochaines étapes : blog, newsletter, paiement

### Exercice
**Action :** Rédige le titre et la meta description de ta page d'accueil. Soumets ton sitemap à Google Search Console.

### Ressources
- Vidéo 06
- Fiches récap SEO (PDF)

### Script vidéo
```
Ton site est en ligne. Mais s'il n'apparaît pas sur Google, il ne sert à rien.

Étape 1 : title et meta description
Chaque page doit avoir un titre unique et une description de 150-160 caractères.

Étape 2 : sitemap et robots.txt
Demande à Lovable de les ajouter. Ils aident Google à indexer tes pages.

Étape 3 : Google Search Console
Va sur search.google.com/search-console, ajoute ton domaine, soumets le sitemap.

Étape 4 : Analytics
Installe Google Analytics 4 ou Plausible pour suivre les visites.

Étape 5 : prochaines étapes
Après le lancement, pense à créer du contenu régulier, ajouter une newsletter, et améliorer avec les retours.

Félicitations, tu as créé ton site web avec l'IA.
```
