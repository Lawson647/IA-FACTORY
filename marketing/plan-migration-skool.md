---

## Objectif
Déployer les 3 formations IA Factory dans la communauté Skool "Les Ateliers IA" en utilisant les niveaux Skool pour débloquer l'accès.

---

## Étapes de migration concrètes

### Étape 1 — Préparer les vidéos (à faire par Guillaume)
- Générer les vidéos HeyGen à partir des scripts fournis
- Exporter en MP4
- Compresser si nécessaire (Skool accepte les vidéos jusqu'à 500 Mo)

### Étape 2 — Créer les cours dans Skool
- Aller dans la communauté Skool
- Cliquer sur "Classroom" puis "Create course"
- Créer les 3 cours avec les leçons
- Uploader les vidéos dans chaque leçon

### Étape 3 — Configurer les niveaux d'accès
- Aller dans les paramètres de la communauté
- Créer les niveaux payants
- Associer les cours aux niveaux :
  - Niveau Pack IA Factory → accès aux 3 cours
  - Niveau Ateliers Pro → accès aux 3 cours + contenu Pro

### Étape 4 — Ajouter les ressources
- Dans chaque cours, ajouter une section "Ressources"
- Uploader les PDFs
- Ajouter les liens externes utiles

### Étape 5 — Créer les quizzes
- Option 1 : créer un post par question avec les réponses en commentaire
- Option 2 : créer un Google Form et mettre le lien dans le cours
- Option 3 : utiliser Typeform ou Tally.so pour un quiz plus joli

### Étape 6 — Tester l'expérience
- Créer un compte test
- Vérifier que les cours gratuits/payants sont bien séparés
- Tester l'achat du niveau Pack
- Vérifier que les cours se débloquent bien

### Étape 7 — Communiquer
- Annonce dans la communauté Skool
- Email aux membres inscrits
- Posts LinkedIn
- Stories Instagram / TikTok

---

## Conseils pour optimiser la conversion dans Skool

- Mettre **1 leçon gratuite** par cours pour donner envie
- Ajouter un **post épinglé** qui explique les niveaux
- Faire une **vidéo de bienvenue** spécifique Skool
- Programmer des **ateliers live** de suivi chaque semaine
- Répondre aux questions dans les commentaires sous 24h

---

## Remarque importante

Skool ne permet pas d'automatiser la création de cours depuis l'extérieur (pas d'API publique).
Tout doit être fait manuellement dans l'interface Skool.

Mais une fois que c'est en place, la vente et le déblocage des niveaux sont automatiques.
