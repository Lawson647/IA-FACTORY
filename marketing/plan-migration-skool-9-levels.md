## Stratégie des levels

### Levels 1-2 : Acquisition
- Objectif : faire rentrer du monde gratuitement
- Contenu : ateliers live, posts, ressources gratuites
- CTA : "Rejoins gratuitement"

### Levels 3-5 : Ventes unitaires
- Objectif : convertir les membres actifs en acheteurs
- Chaque formation est un level séparé
- Permet d'acheter seulement ce qui intéresse

### Level 6 : Pack (upsell)
- Objectif : vendre le bundle à prix réduit
- 149 € au lieu de 207 € si on achète Level 3 + 4 + 5 séparément
- Meilleure valeur perçue

### Level 7 : Affiliation
- Objectif : transformer les acheteurs en vendeurs
- 30 % de commission
- Bonus gamifié avec les points Skool

### Level 8 : Premium
- Objectif : monétiser l'accompagnement
- 299 €/mois avec coaching et revu personnalisé

### Level 9 : Élite
- Objectif : fidéliser les meilleurs membres
- Statut symbolique + opportunités de collaboration

## Comment configurer les levels dans Skool

### Étape 1 — Créer les levels payants
1. Aller dans **Settings** de la communauté Skool
2. Cliquer sur **Levels**
3. Créer les levels 3, 4, 5, 6, 8 avec les prix correspondants
4. Laisser les levels 1, 2, 7, 9 gratuits

### Étape 2 — Associer les cours aux levels
1. Créer les 3 cours dans **Classroom**
2. Dans les paramètres de chaque cours, définir le level minimum :
   - "10 prompts" → Level 3 minimum
   - "Agent IA" → Level 4 minimum
   - "Pipeline contenu" → Level 5 minimum
3. Pour le Pack (Level 6), il suffit que les 3 cours soient aussi accessibles à partir du Level 6

### Étape 3 — Gérer Level 7 Ambassadeur
1. Créer un canal privé "Ambassadeurs"
2. Débloquer ce canal à partir du Level 7
3. Envoyer le lien d'affiliation aux membres Level 7+
4. Suivre les ventes manuellement (Skool ne gère pas les commissions automatiquement)

### Étape 4 — Gérer Level 8 Pro
1. Créer un canal privé "Ateliers Pro"
2. Planifier un coaching groupe mensuel dans les événements Skool
3. Ouvrir un formulaire de revu d'agent pour les membres Level 8

### Étape 5 — Gérer Level 9 Mentor
1. Passage manuel sur invitation
2. Créer un rôle "Mentor" reconnu
3. Co-animer des ateliers avec Guillaume

## Points d'attention

1. **Skool ne fait pas d'affiliation automatique** : il faut suivre les ventes manuellement ou utiliser Stripe avec des liens trackés
2. **Les vidéos doivent être uploadées une par une** : pas d'import en masse
3. **Les PDFs se mettent dans les ressources** : prévoir un stockage cloud si trop lourd
4. **Le passage de level 6 à 7 est manuel** : il faut identifier les bons ambassadeurs
