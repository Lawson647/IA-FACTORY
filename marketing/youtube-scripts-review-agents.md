## Vidéo 1 : J'ai testé 5 agents IA pour remplacer mon assistant

### Hook (0:00 - 0:30)
"J'ai passé 30 jours à tester 5 agents IA. Résultat ? J'ai gagné 12 heures de travail. Dans cette vidéo, je te dis lequel vaut vraiment le coup... et je te donne les liens pour les tester toi-même."

### Intro (0:30 - 1:00)
- Présentation rapide IA Factory
- Pourquoi les agents IA explosent en 2025
- Promesse : un comparatif honnête, pas de bullshit

### Partie 1 : Qu'est-ce qu'un agent IA ? (1:00 - 2:00)
- Définition simple : un robot logiciel qui agit sans intervention
- Différence chatbot vs agent
- Cas d'usage : email, prospection, création de contenu, compta, support client

### Partie 2 : Les 5 agents testés (2:00 - 10:00)
Pour chaque agent :
- Nom + prix
- Ce qu'il promet
- Test écran (3-4 minutes chacun)
- Verdict rapide

Agents recommandés dans l'ordre de la vidéo :
1. **Lindy** — workflows multi-étapes
2. **Relevance AI** — agents workforce B2B
3. **n8n + IA** — automatisation open-source
4. **Phantombuster** — prospection LinkedIn
5. **Vapi** — agent vocal

### Partie 3 : Comparatif final (10:00 - 12:00)
- Tableau comparatif
- Meilleur rapport qualité/prix
- Meilleur pour débutant
- Meilleur pour entreprise

### CTA (12:00 - 13:00)
- Liens affiliés en description
- Pack IA Factory pour apprendre à créer tes agents
- Rejoindre Skool pour poser des questions
