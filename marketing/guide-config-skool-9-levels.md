# Guide pas à pas — Configurer les 9 levels dans Skool

## Important : le fonctionnement de Skool Levels

Dans Skool, les levels montent **automatiquement avec l'engagement** des membres :
- Likes
- Commentaires
- Posts
- Invitations
- Participation aux ateliers
- Cours terminés

Tu ne vends pas un level. Tu peux par contre **vendre des formations complètes** en parallèle, et **débloquer des modules ou ressources à certains levels**.

---

## Avant de commencer

Tu auras besoin de :
- Ton compte Skool admin de la communauté "Les Ateliers IA"
- La liste des 9 levels et des points requis (voir ci-dessous)
- Environ 30 minutes

## Étape 1 — Ouvrir les paramètres Levels

1. Va sur **https://www.skool.com/les-ateliers-ia-8991/classroom**
2. Clique sur ton **profil** en haut à droite
3. **Community settings**
4. Dans le menu de gauche, clique sur **Levels**

---

## Étape 2 — Configurer les points gagnés

1. Dans la page Levels, cherche **"Points"** ou **"Gamification"**
2. Définis les actions suivantes :

| Action | Points |
|--------|--------|
| Aimer un post | +1 |
| Commentaire | +2 |
| Créer un post | +5 |
| Inviter un membre qui rejoint | +10 |
| Terminer une leçon | +5 |
| Participer à un atelier live | +25 |
| Témoignage avec résultat | +50 |

3. Sauvegarde

## Étape 5 — Connecter Stripe pour vendre les formations

Les levels eux-mêmes sont gratuits. Mais tu peux vendre des formations complètes.

1. Va dans **Settings → Payments**
2. Clique sur **Connect Stripe**
3. Connecte ton compte Stripe
4. Remplis les informations bancaires

Formations à vendre (prix suggérés) :
- 10 prompts pour gagner 2h/jour : 49 €
- Créer ton premier agent IA : 79 €
- Pipeline de contenu IA : 79 €
- Pack IA Factory (3 formations) : 149 €

## Étape 8 — Configurer le programme Ambassadeur (Level 7)

1. Crée un canal privé **Ambassadeurs** (Level 7+)
2. Dans ce canal, envoie un message expliquant le programme :
   - Commission : 30 % sur les ventes du Pack IA Factory
   - Lien d'affiliation : Stripe Payment Link personnalisé par ambassadeur
   - Code promo optionnel
3. Crée un Payment Link Stripe par ambassadeur avec un paramètre `?ref=prenom` pour suivre

## Étape 9 — Publier le post d'annonce

1. Va dans le feed Skool
2. Crée un nouveau post
3. Utilise le texte du fichier `marketing/post-annonce-skool-9-levels.txt`
4. Ajoute une image de bannière (optionnel)
5. Épingle le post

## Étape 10 — Tester le parcours

1. Crée un compte test avec un email différent
2. Like et commente 5 posts → vérifie que tu passes Level 2
3. Continue à interagir → vérifie le passage aux levels 3, 4, 5
4. Vérifie que les cours se débloquent bien à chaque level
5. Teste l'achat d'une formation via Stripe

## En cas de problème

**Les levels ne montent pas**
→ Vérifie que les points sont bien configurés dans les paramètres Levels.

**Un cours ne se débloque pas**
→ Vérifie le "Minimum level" dans les paramètres du cours.

**Stripe n'apparaît pas**
→ Vérifie que tu es bien admin et que Stripe est connecté dans Settings → Payments.
